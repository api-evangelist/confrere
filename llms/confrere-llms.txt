# Confrere

> Confrere is a privacy-first, embeddable video-consultation platform (a Compodium product) used by healthcare providers, therapists, consultants, and tutors for secure, encrypted 1-to-1 and small-group video calls that clients join from a browser with no download. The server-side API mints single-use, one-minute room URLs and lets integrators invalidate rooms or eject users.

## APIs

- [Confrere Video API (OpenAPI 3.0)](openapi/confrere-video-openapi.yml): POST /api/token to create a room URL; POST /api/room/{id}/invalidate and POST /api/room/{id}/{userId}/invalidate to end sessions or eject users.
